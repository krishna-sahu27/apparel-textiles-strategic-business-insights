# Data folder

The reproducible synthetic dataset is generated by running python src/data_generation.py or python src/run_analysis.py.

All records are fictional. The generator uses a fixed random seed for repeatability.

## Fields
- month: month-start date
- category: apparel category
- channel: Online or Retail Store
- gross_units: units sold before returns
- returned_units: units returned
- average_list_price_inr: illustrative average list price
- discount_rate: illustrative discount fraction
- net_sales_inr: sales after discounts and estimated returns
- cost_of_goods_sold_inr: illustrative cost of goods sold
- marketing_spend_inr: illustrative channel marketing allocation
